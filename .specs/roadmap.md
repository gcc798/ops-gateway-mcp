# Roadmap

## V0.1
面向受信任内部开发者。已落地 Echo v5、React Web、单二进制、SQLite 资源存储、MCP Streamable HTTP、PostgreSQL/MySQL AST Policy、Linux/K8s 固定能力、Web 确认单、SQLite Audit、JSON Daily Log 与 Prometheus Metrics。资源与 Audit 支持分页筛选，Web 支持明文查看配置及刷新登录保持。

不要求多租户、RBAC、OAuth、Vault、Redis、MQ、微服务、Operator、Plugin Marketplace 或分布式 HA。

## 后续候选
在线配置编辑、配置历史/回滚、更完整 SQL Grammar 可后续按需讨论。本项目不做 RBAC、不可篡改审计、TLS、远程部署或 HA，也不把这些作为后续交付承诺。
