# Roadmap

## V0.1
已落地 Monorepo、Echo v5、React Web、单二进制、typed ConfigManager、MCP Streamable HTTP、PostgreSQL/MySQL AST Policy、Linux/K8s 固定能力、不可替换的确认单、SQLite Audit、JSON Daily Log 与 Prometheus Metrics。

不要求多租户、RBAC、OAuth、Vault、Redis、MQ、微服务、Operator、Plugin Marketplace 或分布式 HA。

## 后续候选
V0.2：在线配置编辑/save、运行时 reload、历史/回滚、更完整 SQL Grammar、OpenTelemetry、Agent identity、Secret Provider。V0.3+：远程多用户部署、认证/RBAC/OAuth、Vault/Secret Manager、HA。未实现能力保持明确边界，不为凑功能引入半成品。
